# TITRATIONSTOOL v15.5.2 – kompakte Titrationsapparatur

Diese Reparaturversion baut die Apparatur innerhalb der tatsächlich verfügbaren Breite neu auf. Bürette, Becherglas und Elektrode sind eindeutig angeordnet; die Anzeige bleibt breit genug für den vollständigen pH-Wert. Tropfen- und Schlierenanimation bleiben erhalten. Die fachliche Berechnung und der Export wurden nicht verändert.
