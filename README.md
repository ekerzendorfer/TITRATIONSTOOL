# TITRATIONSTOOL v15.6.3 – erweiterter Kandidatenpool

## Zweck dieser Version

v15.6.3 schließt die inhaltliche Kernarbeit am Aufgabenbereich ab. Die Aufgabe **„Unbekannte schwache Säure – Identifikation aus dem HÄP“** verwendet nun fünf deutlich unterscheidbare Kandidaten.

## Neu aufgenommen

### Chloressigsäure

- Formel: ClCH₂COOH
- molare Masse: 94,497 g·mol⁻¹
- pKₛ: 2,86
- deutlich stärker als Ameisensäure

### Pyridiniumchlorid

- Formel des eingesetzten Salzes: C₅H₆NCl
- molare Masse: 115,560 g·mol⁻¹
- titrierte Säurespezies: Pyridinium-Ion C₅H₅NH⁺
- pKₛ des Pyridinium-Ions: 5,23

## Kandidaten der HÄP-Challenge

1. Chloressigsäure – pKₛ 2,86
2. Ameisensäure – pKₛ 3,75
3. Benzoesäure – pKₛ 4,20
4. Essigsäure – pKₛ 4,76
5. Pyridinium-Ion aus Pyridiniumchlorid – pKₛ 5,23

Bei „Aufgabe neu laden“ wird weiterhin eine andere Zufallsvariante erzeugt. Eine unmittelbare Wiederholung derselben Säure wird vermieden. Das Äquivalenzvolumen bleibt im moderaten Bereich von 9 bis 15 mL.

## Zusätzlich im freien Labor

Beide Stoffe stehen auch im freien Labor unter **Schwache Säure** zur Verfügung. Die vorhandene Rechenlogik für einprotonige schwache Säuren wird unverändert verwendet.

## Unverändert

- MESSWERT_LAB-Schnittstelle 1.0
- Berechnung von Titrationskurven und Ableitungen
- Äquivalenzpunktbestimmung
- übrige Aufgaben und geführte Auswertungen
- CSV-Export

## Datengrundlage

Die Stoffdaten wurden für diese Version mit NIST/PubChem und einer OECD-Stoffbewertung abgeglichen.
